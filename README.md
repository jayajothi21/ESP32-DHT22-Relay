# ESP32 DHT22 Temperature Based Relay Control

## Project Description
This project uses an ESP32 and DHT22 sensor to monitor temperature.
When the temperature goes above 30°C, the relay is turned ON.

## Components Used
- ESP32
- DHT22 Temperature Sensor
- Relay Module
- Wokwi Simulator

## Working
1. DHT22 measures the temperature.
2. ESP32 reads the temperature value.
3. If the temperature is above 30°C, the relay turns ON.
4. The relay can be used to control a pump or other device.
